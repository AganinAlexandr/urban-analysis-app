# Техническое задание на разработку приложения
## "Извлечение и анализ данных из файлов по программе городская среда"

### 1. ОБЩИЕ СВЕДЕНИЯ

#### 1.1 Назначение системы
Разработка веб-приложения для извлечения, обработки и анализа данных отзывов о городской среде с возможностью визуализации результатов на карте и в виде аналитических диаграмм.

#### 1.2 Тип приложения
- **Архитектура**: Веб-приложение с клиентской архитектурой
- **Платформа**: Веб-браузер (кроссплатформенное)
- **Язык программирования**: Python (Flask)
- **Интерфейс**: Веб-интерфейс с интерактивными элементами

#### 1.3 Целевые пользователи
- Аналитики городской среды
- Исследователи социальных данных
- Административные работники

### 2. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

#### 2.1 Управление данными

##### 2.1.1 База данных
- **Тип**: SQLite база данных с нормализованной структурой
- **Назначение**: Хранение обработанных данных отзывов и объектов
- **Структура**: Основные таблицы и их назначение:

**Таблица `objects`** - Основная информация об объектах:
- `id` - Уникальный идентификатор объекта
- `name` - Название объекта
- `address` - Адрес объекта
- `latitude` - Широта (географическая координата)
- `longitude` - Долгота (географическая координата)
- `group_name` - Название группы объекта (школа, больница, университет и др.)
- `group_id` - Ссылка на таблицу групп
- `created_at` - Дата создания записи
- `updated_at` - Дата последнего обновления

**Таблица `reviews`** - Отзывы пользователей:
- `id` - Уникальный идентификатор отзыва
- `object_id` - Ссылка на объект
- `review_text` - Текст отзыва
- `rating` - Рейтинг отзыва (1-5)
- `sentiment_category` - Категория сентимента (положительный, отрицательный, нейтральный)
- `review_embedding` - Векторное представление отзыва (JSON массив)
- `object_embedding` - Векторное представление совокупного текста объекта (JSON массив)
- `created_at` - Дата создания отзыва
- `source_file` - Исходный файл, из которого загружен отзыв

**Таблица `sentiment_analysis`** - Результаты анализа сентиментов:
- `id` - Уникальный идентификатор анализа
- `review_id` - Ссылка на отзыв
- `method_name` - Название метода анализа (vader, yandex_gpt, openai_gpt и др.)
- `sentiment_score` - Числовая оценка сентимента
- `sentiment_label` - Текстовая метка сентимента
- `confidence` - Уверенность в результате (0-1)
- `created_at` - Дата проведения анализа

**Таблица `object_groups`** - Справочник групп объектов:
- `id` - Уникальный идентификатор группы
- `name` - Название группы (школа, больница, университет и др.)
- `display_name` - Отображаемое название на русском языке
- `color` - Цвет для отображения на карте
- `keywords` - Ключевые слова для автоматического определения группы
- `created_at` - Дата создания группы

**Таблица `embeddings_cache`** - Кэш эмбеддингов:
- `id` - Уникальный идентификатор записи
- `text_hash` - Хеш текста для предотвращения дублирования
- `embedding_data` - Векторное представление текста (JSON массив)
- `model_name` - Название модели YandexGPT
- `token_count` - Количество токенов в исходном тексте
- `created_at` - Дата создания эмбеддинга
- `expires_at` - Дата истечения срока действия

- **Миграция данных**: Из JSON файлов в БД с автоматическим определением групп
- **Очистка данных**: Возможность полной очистки с сохранением структуры таблиц
- **Индексы**: Оптимизированные индексы для быстрого поиска по группам, сентиментам и координатам

##### 2.1.2 Добавление новых данных
- **Функция**: Добавление обработанных отзывов к существующим данным
- **Проверка дубликатов**: Предотвращение повторного добавления существующих отзывов
- **Автоматическое определение групп**: На основе содержимого файла

##### 2.1.3 Управление данными
- **Информация о базе данных**: Отображение статистики:
  - Количество отзывов по группам объектов
  - Заполненность полей
  - Общее количество записей

- **Очистка базы**: Кнопка "Очистить БД" для удаления всех записей

#### 2.2 Обработка входных данных

##### 2.2.1 Поддерживаемые форматы
- **JSON файлы**: Основной формат входных данных


##### 2.2.2 Методы обработки
**Классические методы ML:**
- NLTK и VADER для анализа сентиментов
- Классификация отзывов (положительные, отрицательные, нейтральные)
- Определение типов отзывов (благодарность, жалоба, предложение, информационный)
- Разделение сложных отзывов на части

**Большие языковые модели (LLM):**
- OpenAI GPT (GPT-3.5-turbo, GPT-4) - высокая точность, многоязычность
- Google Gemini Pro - мощный анализ, контекстное понимание
- YandexGPT - оптимизирован для русского языка
- GigaChat - российская модель от Сбера
- Qwen - модель от Alibaba с поддержкой русского
- DeepSeek - современная модель с высокой точностью

**Преимущества LLM анализа:**
- Понимание контекста и нюансов языка
- Обработка сложных конструкций и сленга
- Адаптация к различным стилям написания
- Высокая точность определения сентимента
- Возможность анализа эмоциональных оттенков

##### 2.2.3 Автоматическое определение групп
- **Анализ содержимого файла**: Объединение всех текстов в единый блок для анализа
- **Ключевые слова**: Для каждой группы объектов
- **Нормализация и стемминг**: Обработка русских слов для улучшения точности
- **Обработка пограничных случаев**: Показ групп с одинаковым рейтингом

##### 2.2.4 Система эмбеддингов
- **Назначение**: Семантический анализ и кластеризация отзывов для выявления скрытых паттернов
- **Технология**: YandexGPT API для генерации векторных представлений текста
- **Типы эмбеддингов**:
  - **review_embedding**: Векторное представление отдельного отзыва
  - **object_embedding**: Векторное представление совокупного текста объекта
- **Гибридная система токенов**: OAuth для долгосрочного доступа, IAM для краткосрочного/резервного
- **Автоматическое обновление токенов**: Система мониторинга и обновления API ключей
- **Оптимизация API**: Ограничение длины текста до 2048 токенов для соответствия лимитам YandexGPT

##### 2.2.5 3D визуализация эмбеддингов
- **Режимы кластеризации**:
  - **Группы**: Кластеризация по типам объектов (школы, больницы, университеты и др.)
  - **Сентимент**: Кластеризация по эмоциональной окраске отзывов
  - **Группы+Сентимент**: Комбинированная кластеризация для выявления сложных паттернов
- **Цветовая схема**: 
  - Группы: цвета как на интерактивной карте
  - Сентименты: цвета как в таблице сентиментов
  - Комбинированный режим: автоматическая палитра для до 20 кластеров
- **Фильтрация**: Независимые фильтры по группам, объектам и сентиментам
- **Отображение данных**:
  - В режиме "Группы": review_embedding (мелкие маркеры) + object_embedding (крупные ромбы)
  - В других режимах: только review_embedding
- **Интерактивность**: 3D диаграмма с возможностью вращения, масштабирования и наведения

#### 2.3 Валидация данных

##### 2.3.1 Проверка обязательных полей
**Минимальные требования для обработки:**
- Текст отзыва
- Название объекта (для JSON файлов)

**Минимальные требования для сохранения в БД:**

- Текст отзыва

- **Валидация структуры**: Проверка корректности JSON/CSV форматов

#### 2.4 Геокодирование и картография

##### 2.4.1 Геокодирование адресов
- **Сервис**: Яндекс.Геокодер API
- **Функция**: Определение координат объектов из адресов
- **Логика обработки**:
  - Проверка наличия полей latitude и longitude в загружаемых данных
  - Если координаты отсутствуют - выполнение геокодирования
  - Если координаты уже есть - пропуск геокодирования

##### 2.4.2 Интеграция с картами
- **Платформа**: Яндекс.Карты
- **Функции**:
  - Отображение объектов на карте
  - Цветовая кодировка по группам объектов
  - Фильтрация по группам (включение/выключение)
  - Информационные окна с данными объектов
  - Кнопки "Выбрать все" и "Снять выбор"

#### 2.5 Анализ данных

##### 2.5.1 Анализ сентиментов
- Классификация на положительные, отрицательные и нейтральные
- Определение эмоциональной окраски текстов отзывов
- Определение типов отзывов (благодарность, жалоба, предложение, информационный)

##### 2.5.2 Визуализация данных

- **Графики**: Статистические диаграммы по группам
- **Тепловые карты**: Корреляции между методами анализа

##### 2.5.3 Разделение сложных отзывов
- Выявление отзывов со смешанной тональностью
- Разделение на положительные и отрицательные части
- Анализ каждой части как отдельного отзыва
